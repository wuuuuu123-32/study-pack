# 加图判据

## 1. 通用内核（与学科无关）

**一段内容需要配图，当且仅当它承载的信息本质上是空间 / 结构 / 拓扑关系——只能用位置、形状、方向、连接说清，而不能用数值大小说清。**

反过来：**能用数值或大小说清的，用表格，不要画示意图。**

## 2. 关系类型清单（通用）

| 类型 | 含义 | 各科例子 |
|---|---|---|
| 路径 / 轨迹 | 点之间怎么走 | 热力学 p–V 路径、函数图像 |
| 形状 / 边界 | 区域轮廓 | 积分区域、场线 |
| 方向 / 绕向 | 箭头、流向、顺序 | 循环绕向、电路参考方向 |
| 结构 / 组成 | 部件怎么搭 | 气缸装置、电路图、分子结构 |
| 拓扑 | 包含 / 连接 / 交叉 | 交叉回路、网络图 |
| 数值对比 | ✗ **淘汰** | 改用表格 |

## 3. 怎么用：先三问，再找线索

### A. 配图三问（这才是判据）

一段内容该不该配图，问三件事：

1. **正文引用的对象，在图上能不能指出来？** 读者读到「这个角」「这条线」「这一段」「该量」时，
   图上有没有对应的标签？指不出来 = 图上缺东西，或者根本不该用文字说这件事。
2. **这张图有没有支持一次判别或一次推理？** 图不是装饰。它应该让读者**看着图就能做一次判断**
   （这条光线往哪走、这个量比那个量大、这里是不是会聚）——而不是"公式旁边配张示意图"。
3. **把图遮住，这一步还能不能读下去？** 能读下去 → 这张图是可选的，删掉它把篇幅留给别处；
   读不下去 → 这张图是承重的。

三问里出现一个「否」，就该改图或补标签，而不是加一张新图。

> 为什么不用"出现某词就必须有图"这类触发词规则：它会**诱导无效配图**——
> 正文写了"顺时针"，就画一个跟推理毫无关系的箭头，看上去满足了规则，读者一无所获。
> 规则能数出来的东西，模型就会去凑；所以要问的是「读者要在图上指什么」，不是「文中出现了什么词」。

### B. 特征词只作线索，不作判据

下面这些词通常出现在"用文字干图的活"的地方，可以作为**排查线索**：

"从…到…"、"沿…"、"竖直"、"顺时针 / 逆时针"、"面积"、"更陡"、"回路"、"两端"、"交于"。

命中不等于缺图，只是值得停下来用三问 A 过一遍。**学科清单每次重新列**
（热力学是"路径 / 绕向 / 面积 / 装置结构"；换成化学、电路、数学完全不同，照搬会失效）。

## 3.5 公式里的每一项，图上都得有地方可指

画图时最容易漏的不是"整张图没画"，而是**公式里有一个减项，图上找不到它对应的那条线段**。

判据（逐项对）：

- 公式里出现 **A − B**，图上就必须能分别指出 A 和 B。
- 公式里出现 **2d**，图上就必须看得见为什么是两倍（往返？两条边？）。
- 公式里出现 **一个角**，图上就必须画这个角的弧和标签，并写明它从哪条线量起。
- 推导里出现 **"公共波前 / 等相位面 / 垂足"**，图上就必须真的画出那条辅助线或那个点。

真实例子：薄膜干涉的 `δ = n(AC+CB) − n₁·AD`。图上只画了两条反射光和膜，
`AD` 那段**根本不存在**——读者自然要问"光 1 在膜外那一段等长的几何长度是什么东西"。
补上一个 D 点（从 B 向光 1 出射方向作垂线的垂足）和一条橙色 AD 段，这一项才有地方可指。

**自查方式**：写完之后把公式抄在纸上，用手指在图上一个一个点它的每一项。点不出来的那项就是缺的。

## 3.6 作图断言必须逐条坐标验算

图里凡出现下面三类断言，**都不能"看着像"就交**：

| 断言 | 验算方式 |
|---|---|
| **平行**（"出射光平行于光轴"） | 两条线方向向量叉积为 0，或端点 y 坐标相等 |
| **共点**（"三条光线交于像点"） | 求出每条线与其对应线段的交点，三点距离 < 1px |
| **过某点**（"反向延长线经过 F′"） | 延长线参数方程代进该点坐标，误差 < 1px |

真实事故（2026-11-12，同一张图的三个面板）：
(b) 从焦点射出的光出射后本该**平行于光轴**，画成了斜线；
(c) 平行光入射凹透镜后，反向延长线本该真的**经过 F′**，虚线终点却偏了 8px；
(d) 出射光同样本该平行于光轴。
三处都是"看着差不多"，而它们恰恰是这张图要讲的全部内容。

**做法**：作图先算坐标（像点位置、焦点位置、交点），再把数字填进 SVG，不要手拖。


## 4. 图从哪来

| 来源 | 适用 | 注意 |
|---|---|---|
| **自己画** | 能由公式或数据生成的关系图 | 首选：可复现、可校验、无版权 |
| **截课件 / 教材** | 实物照片、装置外观、特有插图 | 有版权，**不要随公开仓库发布**；背景色与风格常不统一 |

自己画的额外好处：**图上的数值可以和解答里的数值自洽**，而不是"大概长这样"。

## 5. 反例（不该画图的地方）

- 多种情况的数值对比 → 用表格。
- 单一状态的数值计算 → 不需要图。
- 纯公式推导 → 不需要图（除非推导依赖几何关系）。

## 6. 图的质量要求

- 状态点要**标号**，曲线要**标类型**，面积功要**画阴影或标箭头**。
- 只画曲线不标注，等于没画。
