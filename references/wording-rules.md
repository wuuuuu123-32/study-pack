# 措辞与解释规范

## 1. 禁止预设读者学过

| 别写 | 改成 |
|---|---|
| 先复习卡诺循环 | 先把卡诺循环说清楚（组成：…） |
| 回顾上一节 | 上一节说的是…（一句话重申） |
| 如你所知 / 众所周知 | 删掉，直接讲 |
| 显然 / 易得 | 补一步推导，或注明"代入即得" |
| 我们已经学过 | 删掉 |
| 前面提到过 | 前面哪里提到的（文件 + 页码），并重申结论 |

判据：**凡是指向"之前讲过"的话，要么当场重述，要么给出可查的位置。**

## 2. 新名词：三件事

第一次出现必须回答：

1. **是什么**——一句话定义。
2. **为什么要它**——这个概念 / 条件解决什么问题。
3. **它不是什么**——最容易混的那个对照概念。

示例（物理-热力学）：

- **可逆过程**：定义 = 能沿原路返回初态、且外界也完全复原的过程；为什么要它 = 只有它才能让 ∫dQ/T 与路径无关，从而定义出熵这个态函数；它不是什么 = 准静态不等于可逆（准静态但有摩擦仍然不可逆）。

## 3. 新物理量：四要素

1. **定义式**
2. **单位**
3. **类别**：路径无关（态函数）还是路径相关（过程量）
4. **典型值 / 量级**（如果常用）

示例（热力学）：

| 量 | 定义 | 单位 | 类别 |
|---|---|---|---|
| 内能 E | νC_V T | J | 态函数 |
| 功 W | ∫p dV | J | 过程量 |
| 热 Q | Q = ΔE + W | J | 过程量 |
| 熵 S | ∫dQ_rev/T | J/K | 态函数 |
| 摩尔热容 C | Q/(νΔT) | J/(mol·K) | 过程量 |

**特别提醒**：某个公式里出现了某个量，不代表那个条件成立。
例：ΔE = νC_V ΔT 里出现 C_V，但过程未必等容。

## 4. 符号约定

- 全文**只允许一套**。
- 在"读前必看"里**明确写出**选了哪套，并注明另一套的存在与换算关系（通常差一个负号）。
- 用户若用了另一套，先**确认他没错**，再说明只是约定不同。
