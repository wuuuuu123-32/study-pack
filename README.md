# study-pack

> 把一个章节**学扎实**——高效、问题不丢、复习落在自己的坑上。

听课件的速度跟不上、作业又催得紧时，最常见的办法是"直接看答案"——但答案看不懂，
因为缺最基础的那层概念。本 skill 把整件事固化成流水线，产出三份文件：

- **高效**：不用先把几小时课件听完。**讲义**先按"你没学过"的讲法把这一章基础讲一遍，
  再逐题拆「考什么 → 概念是什么 → 公式从哪来 → 怎么下手 → 解答」。
- **记录问题**：你问过的每个问题都落成一条账（连"当时怎么问的""哪块没听懂"都留着）。
  下次不用重问，讲解也不靠记性——**答疑册**。
- **可靠复习**：章节学完，答疑册归纳成**复习卡**：卡点 + 正解 + 一道自检题。
  复习时看到的是**你自己踩过的坑**，不是泛泛的知识点清单。

三份文件分开维护，互不污染。

## 怎么用

### 第一步：把材料给我

至少两样：**课件**（知识点来源）＋ **题目**（作业），题目还要告诉我**题号**。

材料是什么形态都行，常见三种：

**A. 电子课件 + 电子作业题（最省事）**

> 课件：`第10章 热力学基础1.pdf` … `6.pdf`
> 作业：`习题10.pdf`，做第 4、5、7、8、9、10、13、15、17、19、21 题

**B. 题目在纸质书 / 屏幕上 / 老师发的图里**

直接**拍照发给我**。一张图里几道题都行，但**题号要拍清楚**——糊了我就只能猜是第几题，
宁可你再补一张。

**C. 题目在电子课本里**

给课本文件 + 题号（"第 253 页 习题 10-4 到 10-9"这样也行）。

课件我拿到后会先看是**电子版还是扫描版**：

- 有文字层的 PDF → 我能直接搜关键词定位页码，快。
- 扫描版（整页是图）→ 我渲染成图再读，慢一点但一样能用。

### 第二步：开始学

你说一句"从第 4 题开始"就行。之后：

- 每题先讲**知识点**（这题考什么、概念是什么、公式怎么来的），再给**解答**。
- 你随时打断问问题——这不打断流程，反而是答疑册的原料。
- 学完一段说"总结一下"，我出复习卡。
- 最后可以让我照课件目录通检一遍，看讲义漏了哪些知识点。

## 产出

| 产物 | 什么时候有 | 里面是什么 |
|---|---|---|
| **讲义** | 一开始 | 基础总讲 + 逐题知识点与解答 |
| **答疑册** | 边学边记 | 逐条问答账本 |
| **复习卡** | 阶段末尾 | 从答疑册归纳的卡点 + 正解 + 自检题 |

## 三条原则

- **不预设读者学过**：禁用"复习 / 回顾 / 如你所知 / 显然"。
- **可回溯 > 堆砌**：每个知识点都标来源文件与页码，漏了也能自己查回去。
- **分离维护**：讲义、答疑册、复习卡各是各的文件。

## 适用范围与边界

- 适用：有**课件 + 题目**这两个依据的学习材料生产；两种材料来自哪里不限
  （电子文件、扫描件、纸质拍照、屏幕截图都可以）。
- 只有课件、没有题目时：退化成只产**讲义**，不做逐题。
- 不适用：没有依据的纯写作；纯查资料；纯排版美化。
- 本 skill **不含学科知识**。学科专项工具（如图生成脚本）应放在各自项目的 examples 里，
  不要写进本体——否则会把某个学科的特例误当成通用规则。

## 安装

把本目录放进 DSH 的 skills 目录（Windows 下通常是 ~/.dsh/skills/），或在 settings 里启用。
SKILL.md 是入口，references/ 是按需读取的详细规范。
