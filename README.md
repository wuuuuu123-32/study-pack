# study-pack

> 给任何科目、任何章节：把「课件 + 作业题」变成一套可自学的学习材料。

## 它解决什么

听课件的速度跟不上、作业又今晚要交时，最常见的学习方式是"直接看答案"——但答案看不懂，
因为缺少最基础的概念。本 skill 把过程固化成流水线：

1. **讲义**：把整章基础从头讲一遍，再逐题给"考什么 → 概念 → 公式 → 怎么下手 → 解答"。
2. **答疑册**：学习过程中每问一个问题，先把问答落盘成册，再在对话里讲。
3. **复习卡**：阶段末尾从答疑册归纳出卡点与自检题。

三份文件**分开维护**，互不污染。

## 三条原则

- **不预设读者学过**：禁用"复习 / 回顾 / 如你所知 / 显然"。
- **可回溯 > 堆砌**：每个知识点都标来源文件与页码，漏了也能自己查回去。
- **分离维护**：讲义、答疑册、复习卡各是各的文件。

## 安装

把本目录放进 DSH 的 skills 目录（Windows 下通常是 ~/.dsh/skills/），或在 settings 里启用。
SKILL.md 是入口，references/ 是按需读取的详细规范。

## 文件说明

| 文件 | 内容 |
|---|---|
| SKILL.md | 入口：三件套、工作流、8 条硬规则、换科目时的四件事 |
| references/conventions.md | 三件套的格式规格、目录与命名、交付前自查 |
| references/wording-rules.md | 措辞禁令、新名词与新物理量的解释要求 |
| references/figure-rules.md | 加图判据（通用内核 + 学科清单现场生成） |

## 适用范围与边界

- 适用：有**课件 + 题目**这两个依据的学习材料生产。
- 不适用：没有依据的纯写作；纯查资料；纯排版美化。
- 本 skill **不含学科知识**。学科专项工具（如图生成脚本）应放在各自项目的 examples 里，
  不要写进本体——否则会把某个学科的特例误当成通用规则。
